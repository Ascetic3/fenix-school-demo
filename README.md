# Демонстрация сайта школы «Феникс»

Одностраничный сайт на React с переключаемыми информационными разделами.

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Тексты и ссылки находятся в `src/content.js`, разметка — в `src/App.jsx`, стили — в `src/styles.css`.
